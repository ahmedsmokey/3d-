# 🖨️ PRINTFORGE 3D - متجر قطع غيار طابعات ثلاثية الأبعاد
### (3D Printers Spare Parts & Upgrades Platform)

مشروع متكامل ومتطور لمتجر قطع غيار وترقيات طابعات 3D (Bambu Lab, Creality, Prusa, Voron, Elegoo, Anycubic) بالهوية البصرية الجديدة باللونين **الأبيض والبرتقالي**:
- **الباك إند (Backend):** بايثون **Django 6.1** + **Django REST Framework** + **CORS**.
- **الواجهة الأمامية (Frontend):** بيئة **Node.js** + **React 19** + **Vite** + **Lucide Icons**.
- **نظام تسجيل الدخول وحسابات المستخدمين (Authentication):** تسجيل الدخول العادي + **تسجيل الدخول السريع بحساب Google**.
- **قائمة الحساب المنسدلة (User Profile Dropdown):** إظهار اسم المستخدم والصورة والرتبة (مدير أو عميل)، مع خيار وصول مباشر للوحة التحكم للمدراء، وخيار تسجيل الخروج.
- **لوحة التحكم المخصصة (Admin Dashboard):** واجهة داشبورد احترافية ومدمجة لعرض الإحصائيات المرئية وإدارة المنتجات والطلبات والعملاء.
- **قواعد البيانات (Dual Database Strategy):**
  - **وضع التطوير (Development):** **SQLite** تلقائياً وسريع محلياً (`db.sqlite3`).
  - **وضع النشر والإنتاج (Production):** **PostgreSQL** (`psycopg`) عبر متغيرات البيئة.

## 🔐 نظام تسجيل الدخول وحسابات المستخدمين

1. **تسجيل الدخول باستخدام Google (Sign in with Google):**
   - زر مخصص وأنيق يحمل شعار Google يتيح للعملاء الدخول الفوري بضغطة واحدة دون تعقيدات.
2. **تسجيل الدخول بالبريد / اسم المستخدم:**
   - يدعم تسجيل الدخول باسم المستخدم أو البريد الإلكتروني.
   - زر تجريبي فوري لتعبئة بيانات حساب المدير (`admin` / `admin123`) لتجربة لوحة التحكم.
3. **قائمة الحساب الذكية المنسدلة (User Dropdown):**
   - عند تسجيل الدخول، يتحول الزر العلوي ليعرض صورة العميل واسمه ورتبته.
   - عند الضغط عليه تظهر القائمة المنسدلة التي تحتوي على:
     - **لوحة التحكم (الداشبورد):** تظهر فقط للمدراء (`Admin`).
     - **بيانات الحساب:** لمشاهدة الملف الشخصي.
     - **تسجيل الخروج:** لتسجيل الخروج بأمان والعودة لوضع الزائر.
